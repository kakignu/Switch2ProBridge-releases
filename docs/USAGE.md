# 使い方ガイド

Switch2ProBridge のインストールから、キー割り当て・Bluetooth 接続までの手順です。

- 対応: macOS 13 以降（Apple Silicon で動作確認、macOS 26）
- コントローラー: Nintendo Switch 2 Pro Controller

---

## 0. はじめに: このアプリは「公証されていない」アプリです

配布している `Switch2ProBridge.app` は **Apple の Developer ID 証明書で署名・公証（notarization）していません**（ad-hoc 署名のみ）。そのため macOS からは「開発元を確認できないアプリ」として扱われ、次のような対応が必要になります。

| タイミング | 起きること | 必要な対応 |
|---|---|---|
| 初回起動 | 「“Switch2ProBridge”は開いていません」と表示され起動できない | [手順 2](#2-初回起動gatekeeper-の許可) で「このまま開く」 |
| キー割り当てを使うとき | アクセシビリティ許可が必要 | [手順 4](#4-アクセシビリティを許可するキー割り当てを使う場合) |
| **新しいバージョンに入れ替えたとき** | 署名が変わるため、以前の許可が無効になる（ON のままでも効かない） | [アップデート時の注意](#アップデート時の注意証明書なし版) で許可を入れ直す |

> [!IMPORTANT]
> macOS 15 (Sequoia) 以降は、Finder で右クリック →「開く」での回避ができなくなりました。下記の「システム設定 → プライバシーとセキュリティ → このまま開く」を使ってください。

---

## 1. ダウンロードと配置

1. [Releases](https://github.com/kakignu/Switch2ProBridge-releases/releases) から最新の `Switch2ProBridge.zip` をダウンロード
2. zip をダブルクリックして展開
3. `Switch2ProBridge.app` を **`/Applications`（アプリケーション）フォルダへ移動**

> `/Applications` 以外（ダウンロードフォルダなど）から起動すると、macOS がアプリを一時的な場所に移して実行する（App Translocation）ことがあり、アクセシビリティ許可がうまく効かなくなります。必ず移動してから起動してください。

---

## 2. 初回起動（Gatekeeper の許可）

1. アプリケーションフォルダの `Switch2ProBridge` をダブルクリック
2. 次のダイアログが出て起動できません。**「完了」**を押して閉じます（「ゴミ箱に入れる」は押さない）

   ![初回起動時の警告](images/01-gatekeeper-blocked.png)

3. **システム設定 → プライバシーとセキュリティ** を開き、下の方の「セキュリティ」欄までスクロール
4. 「“Switch2ProBridge”は開発元を確認できないため、使用がブロックされました。」の横の **「このまま開く」** を押す

   ![このまま開く](images/02-open-anyway.png)

5. 確認ダイアログで再度「このまま開く」→ Mac のログインパスワード（または Touch ID）で許可
6. 以後は普通に起動できます

<details>
<summary>ターミナルで許可する方法（上級者向け）</summary>

ダウンロード時に付く「隔離属性（quarantine）」を外すと、警告なしで起動できるようになります。

```bash
xattr -dr com.apple.quarantine /Applications/Switch2ProBridge.app
```

署名状態の確認:

```bash
codesign -dv /Applications/Switch2ProBridge.app
# Signature=adhoc と表示されれば ad-hoc 署名（証明書なし）
```

</details>

## 3. USB で接続する

1. 起動するとメニューバーに 🎮 アイコンが出ます（Dock には出ません）
2. コントローラーを USB-C ケーブルで Mac に接続
3. 🎮 をクリックし、**USB 欄が「初期化済み」**、HID 欄が接続中になれば成功。コントローラーのプレイヤー LED 1 が点灯します

   ![メニュー](images/03-menubar.png)

| メニュー項目 | 内容 |
|---|---|
| USB / HID / BT / 入力元 / 押下中 | 接続状態と、いま押しているボタン |
| Bluetoothで接続（SYNC長押し） | BLE 接続を開始（[手順 6](#6-bluetooth-で接続する実験的)） |
| キー/マウス割り当て（HOMEで切替） | 割り当ての ON/OFF |
| プレイヤーLED | 点灯させる LED（1〜4） |
| テスター/ログ | 入力の可視化とログ表示 |
| 割り当て設定… | キー割り当ての編集画面 |
| USB再初期化 | うまく入力が来ないときに初期化をやり直す |

入力の確認は **「テスター/ログ」** で。ボタンが光り、スティック位置・バッテリー・受信レート（Hz）が表示されます。

![テスター](images/06-tester.png)

## 4. アクセシビリティを許可する（キー割り当てを使う場合）

コントローラー操作をキーボード/マウス操作として送るには、macOS の **アクセシビリティ許可** が必要です。

1. メニューの **「アクセシビリティを許可…」** を押す（または割り当てを ON にしたときに表示されるダイアログから）
2. **システム設定 → プライバシーとセキュリティ → アクセシビリティ** で `Switch2ProBridge` を **ON**

   ![アクセシビリティ](images/04-accessibility.png)

3. **アプリを一度終了して起動し直す**（メニューの「終了」→ 再度起動）

> 一覧に出てこない場合は、左下の「＋」から `/Applications/Switch2ProBridge.app` を追加してください。

---

## 5. キー割り当てを設定する

メニューの **「割り当て設定…」** を開きます。

![割り当て設定](images/05-mapping.png)

- 各ボタンの右のメニューから
  - **キーボードのキーを入力…** → 割り当てたいキーを押す（`⌘⇧4` のような修飾キー付きも可）
  - 🖱 左/右/中クリック
  - 割り当てなし
- **Lスティック / Rスティック** の動作: WASD / 矢印キー / 任意の4方向キー / マウス移動 / スクロール / なし
- **感度・しきい値**: マウス速度、スクロール速度、デッドゾーン、キー判定のしきい値
- コントローラーのボタンを押すと、該当する行が光ります
- 変更は即時保存・反映されます
- 最上部の **「割り当てを有効にする」** を ON にすると動作開始。**HOME ボタンでも ON/OFF を切り替え**られます

設定ファイルは `~/Library/Application Support/Switch2ProBridge/profile.json`（「設定ファイルを開く」で開けます）。「初期設定に戻す」でリセットできます。

## 6. Bluetooth で接続する（実験的）

> [!WARNING]
> Bluetooth 接続は実装済みですが、動作検証がまだ十分ではありません。安定して使うなら USB を推奨します。

1. メニューの **「Bluetoothで接続（SYNC長押し）」** を押す
2. 初回は Bluetooth の使用許可ダイアログが出るので **許可**
3. コントローラー上部の **SYNC ボタンを長押し**（LED が流れるように点滅）
4. BT 欄が接続済みになれば完了

- macOS の「システム設定 → Bluetooth」からペアリングする必要は**ありません**（そこからは接続できません）
- 現在は再接続の記憶に対応していないため、**接続のたびに SYNC 長押しが必要**です

## アップデート時の注意（証明書なし版）

ad-hoc 署名のアプリは、バージョンごとに署名（コードの指紋）が変わります。macOS のアクセシビリティ許可は署名に紐づいているため、**新しいバージョンに入れ替えると、設定画面では ON のままなのにキー入力が送られない**状態になります。

アップデートしたら次の手順で許可を入れ直してください。

1. Switch2ProBridge を終了
2. 新しい `Switch2ProBridge.app` を `/Applications` に上書きコピー
3. **システム設定 → プライバシーとセキュリティ → アクセシビリティ** で `Switch2ProBridge` を選び **「−」で削除**
4. アプリを起動 → 「アクセシビリティを許可…」→ ON → **アプリを再起動**
5. 初回起動の「このまま開く」（[手順 2](#2-初回起動gatekeeper-の許可)）も再度必要になることがあります

ターミナルでまとめてリセットする場合:

```bash
tccutil reset Accessibility com.kakinuma.switch2probridge
```

## うまく動かないとき

| 症状 | 確認すること |
|---|---|
| USB 欄が「初期化済み」にならない | ケーブルがデータ通信対応か / 別のポートに挿す / メニューの「USB再初期化」 |
| 入力は来るがキーが送られない | 割り当てが ON か（HOME で切替）/ アクセシビリティが ON か / **アプリを再起動したか** / アップデート直後なら [許可の入れ直し](#アップデート時の注意証明書なし版) |
| アクセシビリティを ON にしても効かない | 一覧から「−」で削除して追加し直す / `/Applications` 以外から起動していないか |
| 起動しない・すぐ落ちる | [手順 2](#2-初回起動gatekeeper-の許可) の許可をしたか |
| Bluetooth が見つからない | SYNC を長押ししているか / Bluetooth の使用許可をしたか |
| 不具合の報告 | 「テスター/ログ」の **コピー** でログを取得し、[Issues](https://github.com/kakignu/Switch2ProBridge-releases/issues) に貼ってください |

## できないこと

- **Apple の GameController 対応ゲーム（App Store のゲームなど）で、ゲームパッドとして直接使うことはできません**。macOS が Switch 2 Pro Controller を認識しないためで、アプリ側では回避できません。キー割り当てを使ってください。
- 振動・ジャイロには未対応です。
